The Primer CLI is available through the `@primer/cli` package. Check to see if the package is installed in the project or globally. If it is not installed, you can install it with `npm install @primer/cli` within a project or with the `-g` flag to install it globally. If the locally installed version is not the latest version, suggest updating it by running `npm update @primer/cli` (or with the `-g` flag if global).

Use the CLI to discover and explore Primer resources in order to build UI. The `--help` flag is available across all commands in order to find additional information.
