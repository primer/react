The Primer CLI is available through the `@primer/cli` package. Check to see if
the package is installed by running `npm list -g @primer/cli`. If it is not
installed, you can install it globally with `npm install -g @primer/cli`. If the
locally installed version is not the latest version, suggest updating it by running `npm update -g @primer/cli`.

Use the CLI to discover and explore Primer resources in order to build UI. The
`--help` flag is available across all commands in order to find additional
information.
