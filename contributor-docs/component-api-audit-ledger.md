## Recording and calibration

Scorecards live in contributor-docs/component-api-audits/; structured per-check inputs live in contributor-docs/component-api-audits/audit-data.json; one aggregator updates this ledger after validation. Parallel graders emit scorecards and data to the caller rather than writing the shared ledger.

Every result uses ADR files present at `2128032dca65a1bd565fe382c2e91c638c6473a4` regardless of status labels, plus gist revision `0f385c865492b0752f19931cc2ae5c7254ef0ad2`, file `0-2026-11-17-base-ui-foundation.md`, SHA-256 `30d60a7e9a5f84e9256ccd2cc2d1e681607257a16d4cb2b739a0fbd6e6cd22e2`. Prior draft scores were Tooltip V2 78.5/B, ActionMenu 70.5/C, Dialog 84.5/B, SelectPanel 70.5/C, and Button 100/A. Corrected scores and reasons are recorded in the component scorecards and [summary](./component-api-audit-summary.md).

The headline scores assume the entire accepted target, including every interactive part, part-level as and both render forms, state-transition callbacks, and CSS-layer requirements. ADR-022-styled-react supersedes ADR-003’s older sx clause for @primer/react; only the compatible package boundary remains relevant. All five audits have zero current-contract defects and zero open BLOCKs. Tooltip V2, ActionMenu, and Dialog have unmeasured Storybook Playwright interaction evidence because Darwin screenshot baselines are absent; Button and SelectPanel focused Playwright interaction tests passed. Human judgment remains pending for all components.

The rubric uses sections weighted 20 / 20 / 25 / 15 / 20. N/A and COVERED rows are excluded from section denominators; limited sections retain their applicable weight and any gaps. NOT MEASURED and UNRESOLVED rows remain unknown in the denominator and keep the result provisional.
