## Target gaps

### S-F1 — Add a consumer-composable SelectPanel parts surface

**Classification / severity / owner:** ADR GAP · FIX · PART-01, section 1; affected checks: PART-01, PART-DOCS, PART-AS, PART-RENDER, MERGE-HANDLER, MERGE-CLASS, MERGE-STYLE-ATTR, MERGE-REF, MERGE-BEHAVIOR.

**Reachable consumer:** A consumer needs to own the trigger, panel layout, input, list, and footer actions beyond the current item/data configuration.

**Observed gap:** SelectPanel exposes an item-configured component and function-only renderAnchor; docs report no subcomponents for a consumer-composable panel.

**Additive fix:** Add an opt-in parts entry point while retaining the existing config/data API, renderAnchor signature, and defaults. Keep exact part names/default elements pending review.

**Pinned citations:** packages/react/src/SelectPanel/SelectPanel.tsx:77-100 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:132-140 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:175-181 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.docs.json:248 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### S-F2 — Add sx to the SelectPanel surface

**Classification / severity / owner:** ADR GAP · FIX · API-01, section 2; affected checks: API-01.

**Reachable consumer:** A consumer needs a local style adjustment to the SelectPanel surface.

**Observed gap:** The component renders a DOM wrapper but SelectPanelProps does not include sx.

**Additive fix:** Add sx to the new parts root and document its target while retaining anchorRef and existing component behavior.

**Pinned citations:** contributor-docs/adrs/adr-003-prop-norms.md:24-30 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:77-100 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:960-961 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### S-F3 — Align the shared open-state contract

**Classification / severity / owner:** ADR GAP · FIX · NAMES-DEFAULTS, section 4; affected checks: NAMES-DEFAULTS.

**Reachable consumer:** Consumers use SelectPanel and ActionMenu together and need a predictable shared open-state name and default model.

**Observed gap:** SelectPanel requires open while ActionMenu documents open as optional with default false.

**Additive fix:** Align the new parts APIs on one open/defaultOpen model and shared default chosen by maintainers; preserve both legacy root contracts and their callbacks.

**Pinned citations:** packages/react/src/SelectPanel/SelectPanel.tsx:77-86 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:132-140 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/AnchoredOverlay/AnchoredOverlay.tsx:67 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/ActionMenu/ActionMenu.docs.json:39-48 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### S-F4 — Align configured SelectPanel class merging with ADR-025

**Classification / severity / owner:** ADR GAP · FIX · MERGE-CONFIG, section 3; affected checks: MERGE-CONFIG.

**Reachable consumer:** A consumer supplies className for the action list rendered within SelectPanel.

**Observed gap:** The consumer class is combined before FilteredActionList's component class, reversing ADR-025's component-first order.

**Additive fix:** Keep current config class behavior during transition; apply the required new-part merge policy on the additive composition API and define an explicit opt-in or versioned migration for the configured root.

**Pinned citations:** contributor-docs/adrs/adr-025-prop-merging.md:24-50 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/SelectPanel/SelectPanel.tsx:1030 @ 2128032dca65a1bd565fe382c2e91c638c6473a4
