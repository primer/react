## Target gaps

### A-F1 — Complete the ActionMenu part substitution contract

**Classification / severity / owner:** `ADR GAP` · FIX · `PART-AS`, section 2; covered checks: `PART-RENDER`, `MERGE-HANDLER`, `MERGE-CLASS`, `MERGE-STYLE-ATTR`, `MERGE-REF`, `MERGE-BEHAVIOR`.

**Reachable consumer:** A consumer needs a custom semantic trigger or overlay while retaining ActionMenu's anchor behavior, refs, and menu lifecycle.

**Observed gap:** ActionMenu.Anchor requires a child element and has no as prop; the rendered parts do not provide the required element/function render contract.

**Additive fix:** Add as support to ActionMenu.Anchor and element/function render support to each rendered part while preserving ActionMenu.Button, Anchor, Overlay, and the configured default export; keep simultaneous as/render precedence pending review.

**Pinned citations:** `packages/react/src/ActionMenu/ActionMenu.tsx:198-209 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/ActionMenu/ActionMenu.tsx:261-267 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/ActionMenu/ActionMenu.tsx:274-282 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/ActionMenu/ActionMenu.tsx:373-384 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/ActionMenu/ActionMenu.tsx:390-394 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`.

### A-F3 — Align the shared open-state contract

**Classification / severity / owner:** `ADR GAP` · FIX · `NAMES-DEFAULTS`, section 4; covered checks: None.

**Reachable consumer:** Consumers use ActionMenu and SelectPanel together and need a predictable shared open-state name and default model.

**Observed gap:** ActionMenu documents open as optional with default false; SelectPanel requires open, so the shared concept has inconsistent default/control shape.

**Additive fix:** Align the new parts APIs on one open/defaultOpen model and shared default chosen by maintainers; retain both legacy root contracts and callback signatures.

**Pinned citations:** `packages/react/src/ActionMenu/ActionMenu.docs.json:39-48 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/SelectPanel/SelectPanel.tsx:77-86 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/SelectPanel/SelectPanel.tsx:132-140 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/AnchoredOverlay/AnchoredOverlay.tsx:67 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`.

### A-F5 — Place ActionMenu styles in the component cascade layer

**Classification / severity / owner:** `ADR GAP` · FIX · `STYLE-01`, section 5; covered checks: None.

**Reachable consumer:** A consumer applies utility-layer styles to ActionMenu; unlayered component rules do not participate in the declared Primer layer order.

**Observed gap:** The authored CSS Module contains no cascade-layer declaration, although ADR-021 and ADR-022 require component styles to use the named primer.components layer.

**Additive fix:** Place the component style rules in @layer primer.components.ActionMenu; retain any globally scoped registrations and all existing selectors and declarations.

**Pinned citations:** `contributor-docs/adrs/adr-021-css-layers.md:66-107 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `contributor-docs/adrs/adr-022-css-layer-names.md:28-65 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/ActionMenu/ActionMenu.module.css:1-70 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`.
