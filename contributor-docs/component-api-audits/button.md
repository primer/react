### B-F1

**Title:** Add both render forms to the Button leaf part

**Status / classification / severity / owner:** DEFERRED — `ADR GAP` · FIX · `PART-RENDER`, section 2; covered checks: `MERGE-HANDLER`, `MERGE-CLASS`, `MERGE-STYLE-ATTR`, `MERGE-REF`, `MERGE-BEHAVIOR`.

**Reachable consumer:** A consumer needs to supply a custom button-like element or component while retaining Button's loading, accessibility, and focus behavior.

**Observed gap:** Button supports as but has no render-element or render-function API.

**Additive fix:** Add element and function render forms to the root part while preserving as, ref, and existing props. Decide how simultaneous as and render values interact before shipping.

### B-F5

**Title:** Place Button styles in the component cascade layer

**Classification / severity / owner:** `ADR GAP` · FIX · `STYLE-01`, section 5; covered checks: None.

**Reachable consumer:** A consumer applies utility-layer styles to Button; unlayered component rules do not participate in the declared Primer layer order.

**Observed gap:** The authored CSS Module contains no cascade-layer declaration, although ADR-021 and ADR-022 require component styles to use the named primer.components layer.

**Additive fix:** Place the component style rules in @layer primer.components.Button; retain any globally scoped registrations and all existing selectors and declarations.

**Pinned citations:** `contributor-docs/adrs/adr-021-css-layers.md:66-107 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `contributor-docs/adrs/adr-022-css-layer-names.md:28-65 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`; `packages/react/src/Button/ButtonBase.module.css:1-733 @ 2128032dca65a1bd565fe382c2e91c638c6473a4`.
