## Target gaps

### B-F1 — Add both render forms to the Button leaf part

**Classification / severity / owner:** ADR GAP · FIX · PART-RENDER, section 2; affected checks: PART-RENDER, MERGE-HANDLER, MERGE-CLASS, MERGE-STYLE-ATTR, MERGE-REF, MERGE-BEHAVIOR.

**Reachable consumer:** A consumer needs to supply a custom button-like element or component while retaining Button's loading, accessibility, and focus behavior.

**Observed gap:** Button supports as but has no render-element or render-function API.

**Additive fix:** Add element and function render forms to the root part while preserving as, ref, and existing props. Decide how simultaneous as and render values interact before shipping.

**Pinned citations:** packages/react/src/Button/Button.tsx:6-16 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Button/types.ts:20-96 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Button/ButtonBase.tsx:44-66 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### B-F2 — Add the ADR-003 sx root prop

**Classification / severity / owner:** ADR GAP · FIX · API-01, section 2; affected checks: API-01.

**Reachable consumer:** A consumer needs a local style adjustment to Button without wrapping it in another styling component.

**Observed gap:** Button renders a DOM button/anchor target, but ButtonProps has no sx prop.

**Additive fix:** Add sx to ButtonProps and apply it to the rendered control while preserving as, refs, className, and existing styling behavior.

**Pinned citations:** contributor-docs/adrs/adr-003-prop-norms.md:24-30 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Button/types.ts:20-96 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Button/ButtonBase.tsx:108-120 @ 2128032dca65a1bd565fe382c2e91c638c6473a4
