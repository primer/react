## Findings

No current-contract defects or applicable ADR gaps were established. `Button` has one primary semantic control, a documented `as` path, and an exported `ButtonBase` for lower-level composition. The proposed ADR does not provide a checkable criterion requiring an additional render prop when a leaf has no separate behavior-bearing part or demonstrated render use case; this applicability decision is recorded for maintainer review.

Evidence: `packages/react/src/Button/Button.tsx:6-11`, `packages/react/src/Button/ButtonBase.tsx:44-59`, `:200`, `:208-210`, `packages/react/src/Button/index.ts:6-7`, `packages/react/src/Button/Button.docs.json:94-103`, `:146`.
