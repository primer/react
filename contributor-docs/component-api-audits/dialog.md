## Target gaps

### D-F1 — Add a consumer-composable Dialog parts surface

**Classification / severity / owner:** ADR GAP · FIX · PART-01, section 1; affected checks: PART-01, PART-DOCS, PART-AS, PART-RENDER, MERGE-HANDLER, MERGE-CLASS, MERGE-STYLE-ATTR, MERGE-REF, MERGE-BEHAVIOR.

**Reachable consumer:** A consumer needs to arrange dialog title, body, footer, trigger, and close behavior without supplying a custom renderer.

**Observed gap:** Dialog.Header, Title, Body, Footer, and related subcomponents are documented as custom-renderer-only and are not intended for direct use.

**Additive fix:** Add an opt-in parts entry point for the modal pattern while preserving Dialog's current config props, renderers, slots, and caller-controlled mount behavior. Keep exact part names/default elements pending review.

**Pinned citations:** packages/react/src/Dialog/Dialog.tsx:316-320 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.tsx:560-575 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.docs.json:58-70 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### D-F2 — Add sx to the Dialog surface

**Classification / severity / owner:** ADR GAP · FIX · API-01, section 2; affected checks: API-01.

**Reachable consumer:** A consumer needs a local style adjustment to the modal dialog body without styling the backdrop.

**Observed gap:** Dialog accepts className and style but not sx; ADR-003 names the inner dialog element as the appropriate target when the outer element is a backdrop.

**Additive fix:** Add sx to DialogProps and apply it to the inner dialog element, retaining className, style, refs, and all current props.

**Pinned citations:** contributor-docs/adrs/adr-003-prop-norms.md:24-26 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.tsx:160-172 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.tsx:414-431 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### D-F3 — Align configured Dialog class merging with ADR-025

**Classification / severity / owner:** ADR GAP · FIX · MERGE-CONFIG, section 3; affected checks: MERGE-CONFIG.

**Reachable consumer:** A consumer supplies className to style the documented Dialog root.

**Observed gap:** The configured Dialog combines consumer className before its component class, reversing ADR-025's component-first order.

**Additive fix:** Preserve existing Dialog class behavior during transition; apply the target merge policy on the new parts API and use an opt-in or versioned migration before changing the configured root.

**Pinned citations:** contributor-docs/adrs/adr-025-prop-merging.md:24-50 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.tsx:414-431 @ 2128032dca65a1bd565fe382c2e91c638c6473a4

### D-F4 — Expose Dialog state transitions on the new root

**Classification / severity / owner:** ADR GAP · FIX · STATE-CALLBACK, section 4; affected checks: STATE-CALLBACK, NAMES-DEFAULTS.

**Reachable consumer:** A consumer needs to observe or veto a close request while using the composable Dialog surface.

**Observed gap:** Dialog reports close gestures through onClose but provides no state-transition callback with the proposed value and cancellation contract.

**Additive fix:** Add an object-shaped open-state callback to the new parts root with value, reason, event when present, and synchronous cancel; preserve onClose(gesture) and caller-controlled mounting on the existing config API.

**Pinned citations:** packages/react/src/Dialog/Dialog.tsx:108-113 @ 2128032dca65a1bd565fe382c2e91c638c6473a4; packages/react/src/Dialog/Dialog.tsx:334-340 @ 2128032dca65a1bd565fe382c2e91c638c6473a4
