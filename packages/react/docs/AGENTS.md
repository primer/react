# AGENTS.md

## Components

Find component docs in `../dist/docs/components/`. Docs for components in `@primer/react` live
directly in this folder. For other entrypoints:

- `@primer/react/deprecated`: `../dist/docs/components/deprecated/`
- `@primer/react/experimental`: `../dist/docs/components/experimental/`
- `@primer/react/next`: `../dist/docs/components/next/`

Each component is a folder that contains a collection of markdown files on the
following topics:

| Topic         | Description                                                       | Always present |
| :------------ | :---------------------------------------------------------------- | :------------- |
| `props.md`    | Lists the component's public props, their types, and descriptions | ✅             |
| `examples.md` | Shows code examples from the component's Storybook stories        |                |
