# Foundations

Presentation comes from Primer design tokens, exposed as Tailwind utilities. Use these rather than raw palette values such as `text-gray-500` or a hardcoded hex, so light, dark, and high-contrast schemes all keep working. A build check fails on any hardcoded colour and on any class that generates no CSS.

When no utility exists for a token, reference the variable directly: `bg-[var(--borderColor-muted)]`.

## Typography

The Primer type scale replaces Tailwind's default one. `text-base`, `text-lg`, and the rest of Tailwind's scale do not exist here.

<div className="text-display">text-display</div>
<div className="text-title-large">text-title-large</div>
<div className="text-title-medium">text-title-medium</div>
<div className="text-title-small">text-title-small</div>
<div className="text-body-large">text-body-large</div>
<div className="text-body-medium">text-body-medium</div>

Each utility sets font size, line height, and weight together. Use `Heading` for section headings so structure stays semantic, and `Text` for inline and block text.

## Focus

One focus treatment applies across the package, so keyboard users see the same affordance everywhere:

```tsx
<button className="focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus" />
```

## Viewport ranges

Primer's ranges map onto Tailwind breakpoints. Narrow is the unprefixed base, so design narrow-first and layer wider ranges on top.

| Primer range | Tailwind prefix | Applies from  |
| ------------ | --------------- | ------------- |
| Narrow       | none            | below `48rem` |
| Regular      | `md:`           | `48rem`       |
| Wide         | `2xl:`          | `87.5rem`     |

`lg:` is `63.25rem` and is **not** the Primer wide range. Components that accept responsive values, such as `PageLayout` and `Stack`, take `{narrow, regular, wide}` objects instead of raw prefixes.

## Spacing and radius

Spacing uses Tailwind's numeric scale against Primer's base unit, so `p-2` and `gap-2` behave as expected. Border radius follows Primer: `rounded-md` is the standard control radius, `rounded-lg` suits larger surfaces, and `rounded-full` produces pills and avatars.
