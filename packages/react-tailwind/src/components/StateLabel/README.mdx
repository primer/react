# StateLabel

`StateLabel` is a Tailwind React component. Import it from `@primer/react-tailwind/StateLabel`.

```tsx
import {StateLabel} from '@primer/react-tailwind/StateLabel'
;<StateLabel status="pullMerged">Merged</StateLabel>
```

## Props

- **`status`** (default: none) — Required: issue, pull request, alert, draft, queue, archived, unavailable, open, or closed status values.
- **`size`** (default: `medium`) — `small` or `medium`.
- **native span props** (default: none) — Includes children and `className`.

## Composition

Use the component-owned status icon with text children that name the state.

## Accessibility

Include visible state text. Component-owned issue, pull request, alert, and archived icons expose their artifact type to assistive technology; the unavailable icon is decorative because it does not identify an artifact type.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The root exposes `data-component="StateLabel"` and `data-status`.
