## Import and usage

```tsx
import {UnderlinePanels} from '@primer/react-tailwind/UnderlinePanels'
;<UnderlinePanels defaultValue="overview">
  <UnderlinePanels.List aria-label="Repository sections">
    <UnderlinePanels.Tab value="overview">Overview</UnderlinePanels.Tab>
  </UnderlinePanels.List>
  <UnderlinePanels.Panel value="overview">Repository activity.</UnderlinePanels.Panel>
</UnderlinePanels>
```

Pair each tab and panel by `value`, provide an accessible name for the list, and use this pattern for local content switching rather than navigation.
