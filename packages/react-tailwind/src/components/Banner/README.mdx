# Banner

`Banner` announces a page-level status or message that needs attention but does not interrupt the user. Use `Dialog` instead when the message must block the task, and inline validation for a single field.

```tsx
import {Banner} from '@primer/react-tailwind/Banner'
;<Banner title="Info" description="A helpful message." />
```

## Props

- **`title` / `description`** (default: none) — Banner heading and supporting content.
- **`variant`** (default: `info`) — `critical`, `info`, `success`, `upsell`, or `warning`.
- **`layout` / `actionsLayout`** (default: `default` / `default`) — Compact visual layout and action arrangement.
- **`flush` / `hideTitle`** (default: `false` / `false`) — Remove outer side borders or visually hide the title.
- **`leadingVisual`, `primaryAction`, `secondaryAction`** (default: none) — Slots for local composition.
- **`onDismiss`** (default: none) — Shows a dismiss control.

## Composition

Use `Banner.Title`, `Banner.Description`, `Banner.Actions`, `Banner.PrimaryAction`, and `Banner.SecondaryAction` for local composition, or pass the corresponding content props.

## Accessibility

Give a banner an accessible name when its title is absent. Dismiss controls receive an accessible label, and a hidden title remains available to assistive technology.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The section exposes `data-component="Banner"`, `data-variant`, `data-layout`, `data-actions-layout`, and state attributes for dismissal, flush, and hidden titles.
