# ButtonGroup

`ButtonGroup` joins related buttons into a single segmented control. Use `SegmentedControl` instead when the buttons select between mutually exclusive views.

```tsx
import {ButtonGroup} from '@primer/react-tailwind/ButtonGroup'
;<ButtonGroup>
  <button type="button">One</button>
</ButtonGroup>
```

## Props

- **`orientation`** (default: `horizontal`) — `horizontal` or `vertical` flex direction.
- **`role`** (default: `group`) — Use `toolbar` for a command toolbar, which moves focus between buttons with the arrow keys.
- **`as`** (default: `div`) — Render a different element type.
- **native HTML props** (default: none) — Includes `aria-label`, `className`, and children.

## Composition

Compose adjacent controls as children; the group does not clone or modify them.

## Accessibility

Label groups of controls with `aria-label`, and use `role="toolbar"` when appropriate. A toolbar keeps one button in the tab order. The arrow keys in its orientation, Home, and End move focus between buttons, wrapping at either end.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The root exposes `data-component="ButtonGroup"` and `data-orientation`.

## Alignment

[ButtonGroup alignment notes](https://github.com/primer/react/blob/main/packages/react-tailwind/src/components/ButtonGroup/ALIGNMENT.md) document intentional differences from the upstream component. Overlay behavior belongs to local tooltip and menu primitives rather than ButtonGroup.
