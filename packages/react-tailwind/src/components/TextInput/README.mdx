# TextInput

A styled native single-line input with small, medium, and large visual sizes, inner visuals, loading, actions, and character-count feedback.

<Canvas of={Stories.Default} />

## Props

<Controls of={Stories.Playground} />

`TextInputProps` extends native input attributes and adds `size`, `block`, `contrast`, `monospace`, `leadingVisual`, `trailingVisual`, `trailingAction`, `loading`, `loaderPosition`, `loaderText`, `validationStatus`, and `characterLimit`. Use native `value`, `defaultValue`, `onChange`, `type`, `name`, `required`, `disabled`, and autocomplete attributes.

## Import

## Accessibility, forms, and validation

Use `FormControl.Label` or `aria-label`; retain native form submission and constraint validation. Set `aria-invalid` and compose `FormControl.Validation` for errors or success feedback. Disabled inputs cannot receive focus or edits.

## Keyboard, events, and state

Native input keyboard behavior and `onChange` are unchanged. The root exposes `data-component="TextInput"` and accepts `className`; focus, disabled, and `aria-invalid` styles are applied through native state selectors.
