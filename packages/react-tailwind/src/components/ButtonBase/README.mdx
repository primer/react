# ButtonBase

`ButtonBase` is the unstyled button primitive behind `Button`, `IconButton`, and `LinkButton`. Reach for it only when building a new button-like control; prefer `Button` for ordinary actions.

```tsx
import {ButtonBase} from '@primer/react-tailwind/ButtonBase'
;<ButtonBase type="button">Do something</ButtonBase>
```

## Props

- **`children`** (default: none) — Button content.
- **`className`** (default: none) — A string or Base UI state callback; base button classes are retained.
- **`data-component`** (default: `ButtonBase`) — Overrides the stable root identifier.
- **native Base UI button props** (default: none) — Includes native button semantics such as `disabled` and `type`.

## Composition

Use as the foundation for locally composed button controls. `Button` builds on this primitive.

## Accessibility

Supply a clear accessible name and use native `type` and `disabled` semantics.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The root defaults to `data-component="ButtonBase"`.
