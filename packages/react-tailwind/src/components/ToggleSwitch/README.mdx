# ToggleSwitch

A form-associated binary switch with small and medium sizes.

<Canvas of={Stories.Default} />

## Props

<Controls of={Stories.Playground} />

`ToggleSwitchProps` forwards Base UI switch props and adds `size`. Use `checked`/`onCheckedChange` or `defaultChecked`, and native form fields such as `name`, `value`, `required`, and `disabled`.

## Import

```tsx
import {ToggleSwitch} from '@primer/react-tailwind/ToggleSwitch'
```

## Accessibility, forms, and validation

Provide an accessible name with a visible label, `aria-label`, or `aria-labelledby`. Checked switches participate in form submission through `name` and `value`. Compose captions and feedback with `FormControl`; disabled switches cannot be toggled.

## Keyboard, events, and state

Space toggles a focused switch. `onCheckedChange` receives the next value and Base UI details. The root exposes `data-component="ToggleSwitch"`, `data-size`, `data-checked`, and `data-disabled`; its thumb mirrors checked and disabled state.
