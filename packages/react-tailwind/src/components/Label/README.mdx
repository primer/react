# Label

`Label` marks an item with a short piece of metadata, such as a status or category. It is presentational and does not label form fields; use `FormControl.Label` for that.

```tsx
import {Label} from '@primer/react-tailwind/Label'
;<Label variant="success">ready for review</Label>
```

## Props

- **`as`** (default: `span`) — Any React element type.
- **`variant`** (default: `default`) — `default`, `primary`, `secondary`, `accent`, `success`, `attention`, `severe`, `danger`, `done`, or `sponsors`.
- **`size`** (default: `small`) — `small` or `large`.
- **native HTML props** (default: none) — Includes children and `className`.

## Composition

Use labels as inline metadata and choose `as` when the surrounding structure needs a different element.

## Accessibility

Include text that communicates the state; color should not be the only cue.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The rendered element has `data-component="Label"`.
