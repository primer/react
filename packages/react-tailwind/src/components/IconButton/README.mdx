# IconButton

`IconButton` is a button whose only content is an icon. `aria-label` is required, because the control has no visible text.

```tsx
import {IconButton} from '@primer/react-tailwind/IconButton'
;<IconButton aria-label="Add item" icon={PlusIcon} />
```

## Props

- **`icon`** (default: none) — Required React element type rendered as the visual.
- **`aria-label`** (default: none) — Required accessible name.
- **`size`** (default: `medium`) — `small`, `medium`, or `large`.
- **button props** (default: none) — Supports Button variants, loading, and native button props except visual children.

## Composition

`IconButton` composes the local `Button` API and owns its icon visual.

## Accessibility

Always provide the required `aria-label`; the icon itself is hidden from assistive technology.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The root is identified as `data-component="IconButton"`.

## Alignment

[IconButton alignment notes](https://github.com/primer/react/blob/main/packages/react-tailwind/src/components/IconButton/ALIGNMENT.md) document intentional differences from the upstream component. Tooltip and menu composition remain in local Tailwind primitives; the component uses native title, aria attributes, and loading state for equivalent fixtures.
