# FormControl

A composable field wrapper that provides label, caption, validation, and control semantics.

<Canvas of={Stories.Default} />

## Props

<Controls of={Stories.Playground} />

`FormControlProps` forwards Base UI Field props and adds `layout: 'horizontal' | 'vertical'`. The public composition includes `Label`, `Caption`, `Validation`, `LeadingVisual`, and `Control`; `Validation` requires an `error` or `success` variant.

## Import and composition

```tsx
import {FormControl} from '@primer/react-tailwind/FormControl'
```

Place `Label`, the native input or `Control`, optional `Caption`, and `Validation` in semantic order. Children are not extracted or reordered.

## Controlled and uncontrolled

`FormControl` does not own field values. Control the nested native input with `value`/`onChange`, or use its `defaultValue` for an uncontrolled field.

## Accessibility, forms, and validation

`Label` associates field text, `Caption` provides description, and error validation uses `Field.Error`; success validation announces with `role="status"`. Forward `disabled` and `name` through the field or child control. Set `aria-invalid` on invalid native controls.

## Keyboard, events, and state

Nested native controls own keyboard and input events. The root exposes `data-component="FormControl"` and `data-layout`; stable subcomponent selectors include `FormControl.Label`, `FormControl.Caption`, `FormControl.Validation`, and `FormControl.Control`.
