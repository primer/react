# Popover

`Popover` pairs a trigger with positioned, dismissible content.

<Canvas of={PopoverStories.Default} />

## Props

<Controls of={PopoverStories.Playground} />

## Usage

```tsx
import {Popover} from '@primer/react-tailwind'
;<Popover>
  <Popover.Button>More information</Popover.Button>
  <Popover.Content>Helpful, non-modal information.</Popover.Content>
</Popover>
```

Give interactive content an appropriate role and label. Keep a visible keyboard focus indicator and a clear close path.
