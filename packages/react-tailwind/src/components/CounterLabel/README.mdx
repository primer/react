# CounterLabel

`CounterLabel` displays a numeric count alongside a label, such as an open-issue total. It is presentational and does not format or abbreviate the number.

```tsx
import {CounterLabel} from '@primer/react-tailwind/CounterLabel'
;<CounterLabel aria-label="12 unread notifications">12</CounterLabel>
```

## Props

- **`variant`** (default: `secondary`) — `primary` or `secondary`.
- **`aria-label`** (default: `({children})`) — Screen-reader label; the visible count is hidden from assistive technology.
- **native span props** (default: none) — Includes children and `className`.

## Composition

Use next to the control or label whose count it qualifies.

## Accessibility

Provide `aria-label` when the generated parenthesized count is not sufficient context.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The visible count has `data-component="CounterLabel"`.
