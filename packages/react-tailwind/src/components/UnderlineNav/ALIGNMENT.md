# UnderlineNav alignment

## From (`@primer/react`)

The current non-deprecated UnderlineNav renders a navigation landmark containing an implicit list of polymorphic items. It supports `variant`, `loadingCounters`, `hideIconsBreakpoint`, `leadingVisual`, counters, `onSelect`, and `aria-current`. When items wrap, it moves clipped items into an ActionMenu.

## To (`@primer/react-tailwind`)

The Tailwind implementation is a presentational `Root`/`List`/`Item` composition. `Root` accepts `variant`, `loadingCounters`, `hideIconsBreakpoint`, and simple presentational `as` replacement. `Item` renders an anchor by default, accepts `leadingVisual`, `counter`, `onSelect`, and `aria-current`, and can use `as` for route-link composition. `List` owns the native list reset, and the root owns single-row horizontal scrolling.

## Migration notes

- **Intentional — composition:** Wrap items in `UnderlineNav.List`. This preserves native `nav`/`ul`/`li`/link semantics without extracting or reordering consumer children.
- **Intentional — responsive overflow:** Overflow remains in the scrollable list instead of moving items to an ActionMenu. This avoids hidden duplicate navigation and keeps consumer route elements and refs intact.
- **Intentional — selection:** The consumer owns `aria-current`; Tailwind does not inspect children or throw when more than one item is current.
- **Parity — counters and visuals:** `loadingCounters` renders a package skeleton for every supplied counter, and `hideIconsBreakpoint` supports the legacy breakpoint values, including `null`.
- **Unsupported — deprecated API:** The legacy `icon` alias is omitted; use `leadingVisual`.
- **Intentional — events:** `onSelect` runs once after an unprevented native click. The legacy key handler could call it in addition to the click generated by Enter.
- **Unsupported — styling system:** Use `className`; `sx` and styled-system props are not available.
