# Flash

`Flash` presents a prominent message with semantic visual variants and an optional full-width layout.

<Canvas of={Stories.Default} />

## Import and usage

```tsx
import {Flash} from '@primer/react-tailwind/Flash'
;<Flash variant="success">Your changes were saved.</Flash>
```

## Composition

Compose text, links, icons, and actions as children. Flash does not own dismissal: place a button beside the content and manage visibility in the parent. Use `full` when the notice spans a page or panel boundary.

## Accessibility

Choose message content and surrounding semantics appropriate to its urgency. If an action is included, give it an accessible name and keep it keyboard reachable. The component does not add an implicit alert role.

## Animation and reduced motion

`Flash` has no animation and does not need reduced-motion handling.

## Theming and Tailwind

Variants use Primer semantic accent, success, attention, and danger tokens. Import package styles or compile with Tailwind v4 and the package `dist` path in `@source`; use `className` for local layout extensions.

### Data attributes

The root exposes `data-component="Flash"`, `data-variant`, and `data-full` when `full` is true.

## Alignment

The local stories cover variants and full-width layout. The dismissible example models visibility with a local button and state because `Flash` itself has no dismiss callback or close-control prop.
