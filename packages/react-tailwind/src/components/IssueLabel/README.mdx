# IssueLabel

`IssueLabel` displays a colored label and can render as a link, button, or custom element for interactive label workflows.

<Canvas of={Stories.Default} />

## Import and usage

```tsx
import {IssueLabel} from '@primer/react-tailwind/IssueLabel'

<IssueLabel variant="red">bug</IssueLabel>
<IssueLabel href="/labels/bug" variant="red">bug</IssueLabel>
```

## Props

<ApiReference {...api} />

`variant` defaults to `gray` and accepts `auburn`, `blue`, `brown`, `coral`, `cyan`, `gray`, `green`, `indigo`, `lemon`, `lime`, `olive`, `orange`, `pine`, `pink`, `plum`, `purple`, `red`, `teal`, or `yellow`. Without `as`, the root is an anchor when `href` is provided, a button when `onClick` is provided, and otherwise a span.

<Controls of={Stories.Playground} />

## Composition

Use a text label that is short enough to scan in lists. Use `href` for navigation or `as="button"`/`onClick` for actions; do not rely on color alone to communicate the label meaning.

## Accessibility

Interactive labels must have meaningful text and an appropriate destination or action. Ensure a custom element receives the keyboard and focus behavior it needs. The chosen color is visual decoration and should be paired with text.

## Animation and reduced motion

Interactive labels use hover and active brightness changes, not motion. No reduced-motion override is required.

## Theming and Tailwind

Preset variants use Primer label color tokens. Import package styles or compile Tailwind v4 with the package `dist` path in `@source`; use `className` for layout extensions. Custom `fillColor` uses inline background and foreground styles and takes precedence over the preset background.

### Data attributes

The root exposes `data-component="IssueLabel"` and `data-variant` for preset variants. `data-variant` is omitted when `fillColor` is supplied.
