# Link

`Link` navigates to another location. Use `Button` when the control performs an action, and `LinkButton` when a navigation target needs button styling.

```tsx
import {Link} from '@primer/react-tailwind/Link'
;<Link href="#docs">Documentation</Link>
```

## Props

- **`as`** (default: `a`) — Any React element type.
- **`muted`** (default: `false`) — Uses muted foreground styling.
- **`inline`** (default: `true`) — Set false for an inline-block link.
- **native anchor props** (default: none) — Includes `href`, children, and `className`.

## Composition

Use the default anchor for navigation, or `as` when composing with an element that owns navigation.

## Accessibility

Provide descriptive link text and a valid destination; do not rely only on surrounding context.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The rendered element has `data-component="Link"`.
