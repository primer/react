# Tooltip

`Tooltip` provides supplementary text for a trigger.

<Canvas of={TooltipStories.Default} />

## Props

<Controls of={TooltipStories.Playground} />

## Usage

```tsx
import {Tooltip} from '@primer/react-tailwind'
;<Tooltip>
  <Tooltip.Trigger>Copy</Tooltip.Trigger>
  <Tooltip.Content>Copy repository URL</Tooltip.Content>
</Tooltip>
```

Tooltips supplement, never replace, the accessible name of their trigger. Do not put essential interactive controls in tooltip content.
