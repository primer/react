# Heading

`Heading` renders a section heading. Choose the level with `as` for document structure and `variant` for visual size, so heading order stays correct independently of scale.

```tsx
import {Heading} from '@primer/react-tailwind/Heading'
;<Heading as="h2">General</Heading>
```

## Props

- **`as`** (default: `h2`) — One of `h1` through `h6`.
- **`size`** (default: `large`) — `small`, `medium`, `large`, or `display`.
- **native heading props** (default: none) — Includes children and `className`.

## Composition

Set `as` from the document outline independently from the visual `size`.

## Accessibility

Maintain a logical heading hierarchy; size is visual and does not change heading level.

## Tailwind extension

Pass `className` to extend the component with Tailwind utilities. The root exposes a stable `data-component` attribute for targeted selectors; use the component's documented data attributes rather than implementation class names.

The heading has `data-component="Heading"`.
