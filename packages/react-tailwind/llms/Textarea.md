# Textarea

`Textarea` is a styled native multiline text control.

Import: `import {Textarea} from '@primer/react-tailwind/Textarea'`

Renders a `<textarea>` and forwards unrecognized props to it, so it also accepts that element's native attributes.

## Props

- `resize`: `"both" | "horizontal" | "none" | "vertical" | null`

## Differences from `@primer/react`

- Replace `block` and pixel-height props with `className` sizing utilities or native rows/cols.
