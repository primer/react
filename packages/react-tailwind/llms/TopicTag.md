# TopicTag

`TopicTag` presents a repository topic as a compact accent-colored tag. `TopicTagGroup` wraps tags into a responsive row.

Import: `import {TopicTag} from '@primer/react-tailwind/TopicTag'`

## Props

- `as`: `React.ElementType`
- `href`: `string`

## Differences from `@primer/react`

- Existing TopicTag and TopicTagGroup composition can generally be retained.
