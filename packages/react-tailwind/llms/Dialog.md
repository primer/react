# Dialog

`Dialog` provides a modal surface with composable trigger and content parts.

Import: `import {Dialog} from '@primer/react-tailwind/Dialog'`

## Content props

- `backdrop`: `boolean`
- `backdropClassName`: `string`
- `portal`: `boolean` — Default `true`.
- `viewportClassName`: `string`

## CloseButton props

- `alignContent`: `"center" | "start"`
- `aria-label`: `string`
- `block`: `boolean`
- `className`: `string`
- `count`: `string | number`
- `disabled`: `boolean`
- `inactive`: `boolean`
- `labelWrap`: `boolean`
- `loading`: `boolean`
- `loadingAnnouncement`: `string`
- `size`: `ControlSize`
- `trailingAction`: `ButtonVisual`
- `variant`: `"danger" | "default" | "invisible" | "link" | "primary"`

## Differences from `@primer/react`

- Migrate custom structure to the Tailwind compound parts.
